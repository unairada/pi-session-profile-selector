> **Please do not file security issues publicly.**
>
> Use [GitHub's private security advisory form](https://github.com/unairada/pi-session-profile-selector/security/advisories/new) instead. If that is not available to you, open a normal issue titled `[SECURITY]` **without details** and a maintainer will reach out.
>
> Pi packages run with your full user permissions. Anything involving unexpected command execution, network calls, or writes outside `~/.pi/agent/` is a security concern and should be reported privately.
